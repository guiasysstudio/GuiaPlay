# GuiaPlay 1.0.2

Patch estável preparado em 14/10/2026 para corrigir o destino do botão da página **Sobre**.

## Correção

- o botão **Abrir página do projeto** foi renomeado para **Abrir página do GuiaSys Studio**;
- o botão agora abre o site oficial da GuiaSys Studio: `https://www.guiasys.online/`;
- o botão não abre mais o repositório do GuiaPlay no GitHub.

## Atualização

Usuários da `1.0.1` poderão receber a `1.0.2` pelo canal Stable após a publicação da Release correspondente.
