# GuiaPlay 0.10.1-prototipo

Release Prototype de 26/09/2026.

## Correção

- as seis cores agora alteram fundo da janela, cards, sidebar, playlist, transporte, status, controles, hover, seleção e bordas;
- 12 paletas profissionais explícitas: seis claras e seis escuras;
- preview de Aparência mostra a identidade visual completa;
- modo Sistema reaplica todas as superfícies quando o Windows muda entre claro e escuro;
- alto contraste continua usando exclusivamente cores do sistema;
- área de vídeo permanece preta e cores Critical/Warning/Success continuam semânticas.

Equalizador, integração Windows, schema 6 e arquitetura de reprodução não foram alterados. A consulta automática real após o startup do M10 foi preservada para a validação física `0.10.0 → 0.10.1`.
