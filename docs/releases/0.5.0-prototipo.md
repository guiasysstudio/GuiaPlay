# GuiaPlay 0.5.0-prototipo

Release Prototype de 25/09/2026.

## Destaques

- atualização via GitHub Releases, com comparação semântica e intervalo automático de 12 horas;
- nova guia **Atualizações** e indicador discreto na janela principal;
- download com `update-manifest.json`, SHA-256 e extração protegida contra Zip Slip;
- `GuiaPlay.Updater` externo, backup e rollback básico;
- proteção de ambiente de desenvolvimento por instalação gerenciada;
- instalador por usuário e distribuição self-contained win-x64;
- scripts reprodutíveis de build e publicação.

## Assets

- `GuiaPlay-0.5.0-prototipo-win-x64.zip`
- `GuiaPlay-Setup-0.5.0-prototipo.exe`
- `SHA256SUMS.txt`
- `update-manifest.json`

Configurações e playlist permanecem em `%LocalAppData%\GuiaSys\GuiaPlay` e não são removidas pela atualização ou desinstalação. O primeiro upgrade público real ocorrerá quando houver uma versão posterior; aplicação e rollback já são testados localmente em diretórios temporários.
