# GuiaPlay 0.10.2-prototipo

Release Prototype de 26/09/2026.

## Polimento visual

- Configurações ganhou uma sidebar estrutural independente de 192 DIPs, com gap real para o conteúdo, clipping protetivo e hover/seleção/foco totalmente contidos;
- sete itens com ícones Fluent, seleção sutil e indicador vertical de accent substituem a apresentação visual dos headers nativos;
- barra operacional ficou aproximadamente 20–22% mais compacta, devolvendo cerca de 26–30 DIPs verticais à Prévia e Playlist;
- Playlist ganhou command bar no cabeçalho, contagem por grupo, ícones de áudio/vídeo, chips de saída e estado vazio orientativo;
- Prévia ganhou estado vazio refinado, mantendo a área de vídeo estritamente preta;
- cabeçalho, status, operador e saídas foram alinhados à hierarquia de superfícies completa do M10.1.

Não há recurso operacional novo. Playback, equalizador, integração Windows, schema 6, instância única e consulta automática real após o startup foram preservados. A versão permite a validação física do update `0.10.1 → 0.10.2`.
