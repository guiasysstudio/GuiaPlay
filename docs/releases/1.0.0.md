# GuiaPlay 1.0.0

Primeira versão estável do GuiaPlay, preparada em 13/10/2026.

## Destaques

- canal de atualização promovido para **Stable**;
- integração comercial com **GuiaSys Licensing / GSL-v1**;
- ativação por chave de licença e vínculo por dispositivo;
- período grátis iniciado somente por ação explícita do usuário;
- período grátis controlado dinamicamente pelo backend e preservado por dispositivo;
- bloqueio de novo trial quando o dispositivo já utilizou/converteu o período grátis;
- gerenciamento da licença com acesso direto à área **Compras e licenças**;
- validação online periódica e autorização offline assinada ES256 dentro da política retornada pelo Licensing;
- atualização automática via GitHub Releases com manifesto e SHA-256;
- pacotes separados para **win-x64** e **win-x86**;
- updater com staging, backup, rollback e preservação dos dados do usuário;
- reprodução local de vídeo e áudio com LibVLCSharp;
- operação multitelas, presets de playlist, aparência e equalizador;
- integração opcional com o Windows Explorer.

## Atualização a partir das versões Prototype

A linha `0.10.x-prototipo` usa o canal Prototype, que aceita uma versão Stable mais nova. Os caminhos `0.10.2-prototipo → 1.0.0` e `0.10.3-prototipo → 1.0.0` estão cobertos por teste automatizado no serviço de atualização.

Quando a Release `v1.0.0` estiver publicada com o `update-manifest.json` e o pacote correspondente à arquitetura instalada, usuários da `0.10.2-prototipo` ou `0.10.3-prototipo` poderão usar **Configurações > Atualizações > Verificar agora** para migrar diretamente para a versão estável.

## Distribuição esperada

A publicação final deve conter, no mínimo:

- `GuiaPlay-1.0.0-win-x64.zip`
- `GuiaPlay-1.0.0-win-x86.zip`
- `GuiaPlay-Setup-1.0.0.exe`
- `GuiaPlay-Setup-1.0.0-win-x86.exe`
- `update-manifest.json`
- `SHA256SUMS.txt`

Os hashes e tamanhos definitivos são gerados pelo `scripts/build-release.ps1` e validados novamente pelo `scripts/publish-release.ps1` no momento da publicação.

## Observações

- esta versão não inclui reprodução do YouTube; esse trabalho fica para uma versão posterior;
- o licenciamento depende do serviço de produção do GuiaSys Licensing;
- o trial é controlado pelo backend por dispositivo e não é reiniciado ao desvincular uma licença paga;
- dados do usuário ficam fora da pasta de instalação e são preservados pelo updater;
- a Release final não deve ser marcada como prerelease.
