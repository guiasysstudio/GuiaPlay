# GuiaPlay 0.10.0-prototipo

Release Prototype de 26/09/2026.

## Destaques

- Interface 2.0 em cartões para mídia, prévia, playlist e transporte;
- Configurações com navegação lateral por Telas, Aparência, Áudio, Atualizações, Windows, Diagnóstico e Sobre;
- modos Sistema, Claro e Escuro com seis cores de destaque e suporte prioritário a alto contraste;
- equalizador nativo do LibVLC, desativado por padrão, com presets/bandas descobertos em runtime, preamp e modo Personalizado;
- persistência e migração segura do schema 6;
- uma consulta real ao GitHub por novo processo, depois do carregamento, mesmo quando existe cache recente;
- indicador de update restaurado imediatamente pelo cache e atualizado diretamente pelo estado do gerenciador;
- preservação da integração Explorer, instância única, robustez M09, instalador per-user e updater verificado.
