# GuiaPlay 1.0.3

Patch estável preparado em 16/10/2026 para migrar os endereços oficiais da GuiaSys para o domínio `.com.br`.

## Alterações

- API do GuiaSys Licensing alterada de `https://licencas.guiasys.online` para `https://licencas.guiasys.com.br`;
- ação de compra/licenciamento passa a abrir `https://licencas.guiasys.com.br/`;
- ação **Gerenciar conta** passa a abrir `https://licencas.guiasys.com.br/conta/compras`;
- botão **Abrir página do GuiaSys Studio** passa a abrir `https://www.guiasys.com.br/`;
- Código de Integração, Project ID, prefixo de licença e protocolo GSL-v1 permanecem inalterados;
- Device ID, licenças existentes, trial e autorização local permanecem compatíveis entre versões.
