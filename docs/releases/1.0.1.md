# GuiaPlay 1.0.1

Patch estável preparado em 14/10/2026 para corrigir a apresentação do licenciamento durante a abertura do aplicativo.

## Correção

- restaura imediatamente, no início do processo, a autorização local protegida em `licensing.dat` quando o entitlement assinado ainda é válido para aquele dispositivo;
- uma instalação já ativada abre diretamente sem exibir a tela de “Verificando licença”/ativação;
- a autorização local não é um simples marcador `ativado=true`: o token ES256, dispositivo, validade, janela offline e relógio observado continuam sendo verificados antes de liberar a interface;
- a revalidação online continua ocorrendo pelo fluxo normal e pelos timers existentes, atualizando o estado protegido quando o servidor confirmar a autorização;
- se não existir uma autorização local válida, o estado de verificação e o fluxo de ativação continuam aparecendo normalmente.

## Segurança e licenciamento

A correção usa o cache protegido que o GuiaPlay já possuía. O programa somente libera a interface imediatamente quando a autorização persistida passa pela verificação criptográfica local; estado ausente, adulterado, expirado ou incompatível continua exigindo validação/ativação normal.

## Atualização

Usuários da `1.0.0` poderão receber a `1.0.1` pelo atualizador Stable já existente após a publicação da Release correspondente.
